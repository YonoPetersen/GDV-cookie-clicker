# Cookie Clicker

## Core mechanic:
Klikken om cookies te verdienen en upgrades kopen voor meer cookies.

## Waarom is dit casual?
Simpel te spelen, korte speelsessies en constante progressie.

## Wat neem je mee voor je eigen game?
Upgrades, idle income en duidelijke feedback voor de speler.
